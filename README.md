# Connect INDIA — Messaging India Forward

Official web platform for **Connect INDIA™**, India's premier enterprise cloud communications (CPaaS) and telecom routing infrastructure.

## 🚀 Key Highlights & Capabilities
- **Omni-Channel Communications:** SMS, RCS Rich Messaging, WhatsApp Business API, Cloud Voice Broadcasting, and IVR.
- **Telecom Tower Infrastructure:** Direct Tier-1 carrier connectivity, sub-2s latency, and 10,000+ TPS routing.
- **Trusted Partners & Clients:** Live interactive showcases for 47+ enterprise leaders in Real Estate, FinTech, and E-Commerce.
- **Enterprise-Grade UI/UX:** Responsive 60fps/120fps continuous scroll-scrubbing animation, 3D arenas, and responsive typography.

## 🛠️ Local Development

```bash
npm install
npm start
```
